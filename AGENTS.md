# Project instructions

Read `CLAUDE.md` and its linked project documentation before substantial work.

## Language

- Communicate with the user in French.
- Write project content, code comments, documentation, and commit messages in English.
- This rule supersedes older exceptions allowing French repository content,
  including the legacy `assets/kiri/` tree. Translate legacy content when it is
  edited; a language preference alone does not require a wholesale rewrite.

## Documentation maintenance

- Verify documentation against source code and package manifests.
- Keep implemented behavior, known defects, future plans, and release history distinct.
- Track remaining documentation work in `docs/DOCTODO.md`.
- Documentation updates do not authorize package version changes.

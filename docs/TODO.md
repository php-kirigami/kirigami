- **HTTPS connection close hangs in the new PHP-WASM cores** (php-wasm-compiler, blocks committing them): since the blocking-recv changes (86e777d onward, still in 89a7958), closing a curl HTTPS connection waits until the server closes it (~6 s against Node's keep-alive), in `curl_exec()` with `CURLOPT_FORBID_REUSE` or when the handle is freed; HTTP is unaffected and the committed core closes in ~10 ms. curl's socket is non-blocking, so the TLS shutdown read should return `EAGAIN` and give up after curl's 2 s shutdown timeout at most; likely curl sets `O_NONBLOCK` in a way the core doesn't track (e.g. `ioctl(FIONBIO)`). It makes `curl-tls.test.js` take ~45 s of its 60 s timeout.
- **VS Code packaging on other platforms**: interactive checks passed (2026-09-23) and the win32-x64 VSIX is built and tested; VSIX builds for other targets are not. See [EXTENSION-VSCODE.md](EXTENSION-VSCODE.md) for reproducible checks.
- **php-wasm: regression test for multi-module phpext packages**: the loader's `register()` path, `mysqlnd` dedup and ini ordering were verified by hand against `../php-wasm-compiler/packages`; no automated test covers them (they need real `.so` artifacts).

- **curl's TCP_NODELAY in the PHP-WASM build** (php-wasm-compiler): libcurl 8.22 never sends `TCP_NODELAY` (its default, or `CURLOPT_TCP_NODELAY`) to the proxy, while `CURLOPT_TCP_KEEPALIVE` arrives, and the verbose log shows no failure; likely `HAVE_NETINET_TCP_H` is unset in the curl build, which compiles `Curl_sock_nodelay()` out. Also minor: `TCP_NODELAY` on a UDP socket succeeds instead of failing. Checked with core 89a7958; once fixed, add a curl case to the socket-options runtime test.
- **mdhtml expands shortcodes inside code** (`../php-mdhtml`, then a PHP-WASM rebuild): with mdhtml 0.1.4, `{% name %}` runs inside inline code spans and indented code blocks (fenced blocks are fine); the old pure-PHP `MD` left them literal. Visible in `template-default`'s About page, where `` `{% lead %}` `` renders as an empty `<code></code>`. Add a php-prepros test once fixed.
